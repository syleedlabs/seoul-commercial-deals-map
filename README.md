# 서울 상업용 통건물 실거래 지도

서울 강남구 상업업무용 **통건물** 실거래(2006~2026)를 3D 지도로 보여 주는 [ANA(Agent-Native Agent)](https://www.anahub.io) 커뮤니티 쇼케이스입니다.

- 지도 위에서 계약연도별로 켜고 끌 수 있고, ▶ 재생을 누르면 서울 전경에서 강남으로 내려가며 거래가 쌓이는 과정을 보여 줍니다.
- 거래가 있는 건물은 대지 평단가(또는 계약연도) 색으로 칠해지고, 건물이나 점을 누르면 그 지번의 거래 이력이 나옵니다.
- 멀리서는 동 단위 집계, 가까이서는 건물 단위로 보입니다.

## 데이터

- 실거래가: 국토교통부 실거래가 공개시스템
- 건물 매칭: 건축HUB 건축물대장 (deal-locator MCP로 마스킹된 지번을 복원)
- 지도: © OpenFreeMap · © OpenMapTiles · 데이터 © OpenStreetMap contributors
- 통건물(유형 '일반')만 포함하며 구분상가는 제외됩니다. 해제된 거래는 제외됩니다.
- 지번을 복원하지 못한 거래와 아직 좌표를 얻지 못한 거래는 점으로 표시되지 않습니다. 특히 2019년 이후는 점 데이터가 아직 일부만 올라와 있습니다. 동 단위 집계는 전 기간이 반영되어 있습니다.

> 이 지도는 참고자료이며 중개대상물 확인·설명서가 아닙니다. 원문은 실거래가 공개시스템·건축물대장에서 확인하세요. 추정매칭은 동일 스펙의 인접 건물일 수 있습니다.

## ANA가 관리합니다

이 저장소는 사람이 직접 편집하지 않고, 맥미니에서 돌아가는 ANA 에이전트가 갱신합니다.
새 실거래를 가져와 지오코딩하고, 지도 데이터를 다시 만들고, 사람이 승인하면 이 저장소에 반영합니다. (최신 신고 반영 · 일 1회 갱신을 목표로 합니다.)
